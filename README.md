# Crop Disease Detection

## Project Description
This project focuses on detecting plant diseases from crop images using image processing and machine learning techniques.

## Objectives
- Identify diseases in crop leaves.
- Analyze plant images to detect possible diseases.
- Support early disease identification in agriculture.

## Tools Used
- Python
- Google Colab
- Image Processing
- Machine Learning

 Project File
